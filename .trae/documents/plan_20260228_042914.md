# Vibe Paper 项目功能增强计划

## 需求分析
1. **多种模型切换**：支持不同的 AI 模型，包括具有深度思考功能的模型
2. **公式编辑支持**：在前端编辑器中支持数学公式的编辑和显示

## 实现方案

### 1. 多种模型切换功能

#### 后端实现
- **模型管理**：在 `ai_service.py` 中添加模型管理功能，支持多种模型的配置和切换
- **API 端点**：添加模型切换的 API 端点，允许前端选择不同的模型
- **深度思考集成**：实现支持深度思考功能的模型调用

#### 前端实现
- **模型选择界面**：在 AI 侧边栏中添加模型选择下拉菜单
- **模型配置**：允许用户配置不同模型的参数
- **深度思考开关**：添加深度思考功能的开关

### 2. 公式编辑支持

#### 前端实现
- **集成公式编辑库**：选择并集成合适的公式编辑库（如 MathJax、KaTeX 或 Monaco Editor 的公式插件）
- **公式编辑按钮**：在编辑器工具栏中添加公式编辑按钮
- **实时预览**：实现公式的实时预览功能
- **公式存储**：确保公式能够正确存储和加载

## 技术实现

### 后端修改
1. **ai_service.py**：
   - 添加模型管理功能
   - 实现不同模型的调用逻辑
   - 添加深度思考功能的支持

2. **api/ai.py**：
   - 添加模型切换的 API 端点
   - 支持模型参数的配置

### 前端修改
1. **PaperEditor.tsx**：
   - 添加模型选择下拉菜单
   - 集成公式编辑库
   - 添加公式编辑按钮

2. **样式调整**：
   - 确保公式编辑界面的样式与整体设计一致
   - 优化公式显示效果

## 预期效果
- **模型切换**：用户可以在不同的 AI 模型之间切换，包括支持深度思考功能的模型
- **公式编辑**：用户可以在论文中插入和编辑数学公式，公式能够正确显示
- **用户体验**：提供流畅的模型切换和公式编辑体验

## 实现步骤
1. 修改后端 `ai_service.py`，添加模型管理功能
2. 修改后端 API，添加模型切换端点
3. 在前端添加模型选择界面
4. 集成公式编辑库到前端
5. 添加公式编辑按钮和功能
6. 测试模型切换和公式编辑功能
7. 优化用户体验
