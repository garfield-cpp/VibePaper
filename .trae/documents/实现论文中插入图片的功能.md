# 实现论文中插入图片的功能

## 前端实现
1. 在 PaperEditor.tsx 中的编辑器工具栏添加 "插入图片" 按钮
2. 实现文件选择功能，允许用户选择图片文件
3. 实现图片上传到后端的功能，使用 FormData 进行文件上传
4. 上传成功后，在编辑器中插入图片的 Markdown 语法 `![alt text](image-url)`
5. 添加上传状态的显示，确保用户体验

## 后端实现
1. 在 server/main.py 中添加图片上传的路由
2. 实现图片上传的 API 端点，使用 FastAPI 的 File 和 UploadFile 处理文件上传
3. 创建图片存储目录，确保不同用户的图片不会冲突
4. 实现图片存储逻辑，包括文件保存和路径生成
5. 提供图片访问的 URL，确保用户可以访问上传的图片
6. 添加认证，确保只有登录用户可以上传和访问图片

## 技术要点
- 前端使用 FormData 进行文件上传
- 后端使用 FastAPI 的文件处理功能
- 图片存储路径设计：`uploads/{user_id}/{paper_id}/{filename}`
- 确保图片访问权限，只允许用户访问自己的图片
- 处理图片文件的命名和存储，避免文件名冲突

## 实现步骤
1. 首先在后端添加图片上传的 API 端点
2. 然后在前端添加插入图片按钮和上传功能
3. 测试图片上传和插入功能
4. 确保图片可以正确显示在论文中
