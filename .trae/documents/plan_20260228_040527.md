# Vibe Paper 项目改进计划

## 问题分析
1. **前端布局问题**：当前前端页面布局只考虑了移动端，在电脑端显示时内容堆在左边，没有充分利用屏幕空间
2. **功能集成问题**：当前 AI 功能与论文编辑功能分离，用户需要在不同页面之间切换，没有实现类似 Trae 的 AI IDE 体验

## 改进方案

### 1. 优化前端布局
- **响应式设计**：使用 Tailwind CSS 的响应式类，针对不同屏幕尺寸优化布局
- **电脑端布局**：在大屏幕上使用多列布局，充分利用屏幕空间
- **编辑器优化**：调整 Monaco Editor 的尺寸和位置，使其在电脑端显示更合理

### 2. 集成 AI 侧边栏
- **在论文编辑器中添加侧边栏**：在 PaperEditor 页面右侧添加 AI 对话功能
- **实时对话**：用户可以在侧边栏中与 AI 进行实时对话
- **AI 直接修改**：实现 AI 对论文内容的直接修改功能

### 3. 功能增强
- **论文大纲生成**：AI 可以根据用户输入生成论文大纲
- **内容润色**：AI 可以对选中的论文内容进行润色
- **引用生成**：AI 可以根据论文内容生成参考文献
- **实时保存**：自动保存论文内容，避免数据丢失

## 技术实现

### 前端修改
1. **PaperEditor.tsx**：
   - 修改布局为左右两栏结构
   - 左侧为论文编辑器
   - 右侧为 AI 对话侧边栏
   - 添加 AI 功能按钮和交互逻辑

2. **样式调整**：
   - 使用 Tailwind CSS 的响应式类
   - 在大屏幕上使用 `grid` 或 `flex` 布局
   - 确保编辑器和侧边栏在不同屏幕尺寸下都能正常显示

3. **AI 集成**：
   - 在侧边栏中实现 AI 对话功能
   - 添加 AI 生成、修改、润色等功能按钮
   - 实现 AI 响应的实时显示

### 后端调整
1. **API 优化**：
   - 确保 AI 相关 API 响应速度
   - 添加更多 AI 功能的 API 端点

## 预期效果
- **电脑端优化**：在电脑端显示时，论文编辑器和 AI 侧边栏并排显示，充分利用屏幕空间
- **AI 集成**：用户可以在编辑论文的同时，在侧边栏与 AI 进行对话，AI 可以直接修改论文内容
- **用户体验**：提供类似 Trae 的 AI IDE 体验，使论文写作更加高效

## 实现步骤
1. 修改 PaperEditor.tsx 的布局结构
2. 添加 AI 侧边栏组件
3. 实现 AI 与论文编辑的交互功能
4. 测试和优化布局响应式
5. 测试 AI 功能的集成效果
