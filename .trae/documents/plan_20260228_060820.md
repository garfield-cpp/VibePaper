# 为模型添加新的 Skill

## 后端实现
1. **添加新的 AI 服务方法**：
   - 在 `AIService` 类中添加 `search_literature` 方法，用于查找文献
   - 添加 `search_github` 方法，用于查找代码仓库
   - 添加 `get_paper_outline` 方法，用于获取当前文章的章节目录
   - 添加 `generate_image` 方法，用于调用图像生成模型生成图片

2. **添加新的 API 端点**：
   - 在 `ai.py` 中添加相应的路由
   - 实现请求和响应的数据模型

3. **集成外部服务**：
   - 集成学术搜索 API（如 Semantic Scholar 或 Google Scholar）
   - 集成 GitHub API 用于代码仓库搜索
   - 集成 OpenAI 的 DALL-E 或其他图像生成 API

## 前端实现
1. **添加新的 AI 功能按钮**：
   - 在 `PaperEditor.tsx` 的 AI 功能按钮区域添加新的按钮
   - 为每个新 skill 添加对应的处理函数

2. **实现前端交互逻辑**：
   - 实现文献搜索功能，显示搜索结果
   - 实现 GitHub 仓库搜索功能
   - 实现获取文章章节目录的功能
   - 实现图像生成和导入功能

3. **更新 UI 界面**：
   - 添加必要的输入表单和结果展示区域
   - 处理加载状态和错误信息

## 技术要点
- 使用 FastAPI 实现后端 API
- 使用 React 实现前端交互
- 集成外部 API 需要处理 API 密钥和认证
- 图像生成后需要上传到服务器并导入到论文中
- 章节目录生成需要分析当前论文内容

## 实现步骤
1. 首先在后端添加新的 AI 服务方法
2. 添加对应的 API 端点
3. 在前端添加新的功能按钮
4. 实现前端交互逻辑
5. 测试各个功能的完整性
