# Vibe Paper 项目功能扩展计划

## 需求分析
1. **登录功能**：支持多用户使用，包括注册、登录、注销功能
2. **多论文管理**：允许用户创建和管理多篇论文，而不仅仅是一篇

## 实现方案

### 1. 登录功能

#### 后端实现
- **用户模型**：创建用户数据模型，包含用户名、密码哈希等信息
- **认证系统**：实现 JWT 认证，包括注册、登录、注销功能
- **API 端点**：添加用户相关的 API 端点
- **中间件**：添加认证中间件，保护需要登录的 API 端点

#### 前端实现
- **登录页面**：创建登录和注册页面
- **导航栏**：添加用户信息和注销按钮
- **状态管理**：使用 React Context 管理用户登录状态
- **路由保护**：保护需要登录的路由

### 2. 多论文管理

#### 后端实现
- **论文模型修改**：修改论文模型，添加用户 ID 字段，关联到用户
- **API 端点修改**：修改论文相关 API 端点，支持按用户查询和管理论文
- **权限控制**：确保用户只能访问自己的论文

#### 前端实现
- **论文列表页面**：创建论文列表页面，显示用户的所有论文
- **论文创建功能**：添加创建新论文的功能
- **论文删除功能**：添加删除论文的功能
- **导航功能**：在不同页面之间导航

## 技术实现

### 后端修改
1. **添加用户模型和认证**：
   - 创建 `app/models/user.py`
   - 创建 `app/schemas/user.py`
   - 创建 `app/services/auth_service.py`
   - 创建 `app/api/auth.py`
   - 添加认证中间件

2. **修改论文模型**：
   - 修改 `app/models/paper.py`，添加 user_id 字段
   - 修改 `app/services/paper_service.py`，添加用户关联逻辑

### 前端修改
1. **添加登录和注册页面**：
   - 创建 `src/pages/LoginPage.tsx`
   - 创建 `src/pages/RegisterPage.tsx`

2. **添加论文列表页面**：
   - 创建 `src/pages/PaperListPage.tsx`

3. **修改路由**：
   - 修改 `src/App.tsx`，添加新路由
   - 添加路由保护

4. **添加状态管理**：
   - 创建 `src/contexts/AuthContext.tsx`

## 预期效果
- **用户认证**：用户可以注册、登录和注销
- **多论文管理**：用户可以创建、查看、编辑和删除自己的多篇论文
- **权限控制**：用户只能访问自己的论文
- **用户体验**：提供流畅的登录和论文管理体验
